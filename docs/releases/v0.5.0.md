> **⚠️ Pre-release for testing.** v0.5 is the first testing build of PDF Manager for **Windows 10/11 (64-bit)**. It is not a finished release: use copies of your documents, and expect rough edges. The full v1.0 will follow after manual verification.

## What PDF Manager does

An offline desktop app for preparing PDF and PowerPoint documents:

- **Flatten**: turn every page into a single image, so PDFs open reliably in apps that struggle with complex PDFs (for example tablet note-taking apps). Optional **OCR** makes the pages searchable again.
- **Flatten + Merge**: flatten several documents and combine them in your order.
- **Merge**: combine documents, keeping text, links and bookmarks; optional clickable contents page.
- **Split**: by page ranges (`1-3, 5, 8-10`), every N pages, or one file per page; save as files or one zip.
- **Images to PDF**: photos and images (PNG, JPG) into one PDF or one PDF per image.
- **Compress**: Light, Balanced or Strong.

Your originals are never changed; results are saved as new files and nothing is overwritten. Everything runs on your computer.

## Install (Windows)

1. Download **`PDF-Manager-Setup-0.5.0.exe`** below.
2. **Double-click it.** The installer isn't signed yet, so Windows SmartScreen may say "Windows protected your PC": click **More info → Run anyway**.
3. Follow the short wizard. It installs for your user only (no administrator rights) and can optionally install **Tesseract OCR** (for searchable text) and **LibreOffice** (only needed without Microsoft PowerPoint). Those two may show a Windows permission prompt.
4. Start **PDF Manager** from the Start menu or the desktop icon.

To uninstall: Windows Settings → Apps → PDF Manager.

## What has been checked

- Automated tests: the Python suite on Linux (with Tesseract and LibreOffice) and on Windows, plus the interface tests, all pass in CI.
- On a GitHub Windows runner, the installer **builds, installs silently, and the installed app starts**: it opens its window, shows the interface and answers through its Python bridge (automated start-up check).

## Not checked yet (please test)

- Everyday use on a real Windows 11 PC: drag and drop, file pickers, saving, Settings, the installer wizard's optional programs, upgrade and uninstall.
- Converting PowerPoint files with **Microsoft PowerPoint** (only tested with a simulated PowerPoint). Presentations downloaded from the internet or email are deliberately converted with LibreOffice instead.
- Very large documents and long OCR jobs.

## Known limitations

- Windows only in this pre-release; Linux packages (Ubuntu/Debian, Arch) are planned for **v0.75**.
- The installer is unsigned (SmartScreen warning).
- OCR reads one language at a time (English by default; change it in Settings).

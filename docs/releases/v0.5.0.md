# PDF Manager v0.5.0

The proposed stable v0.5.0 build is a portable app for Windows 11 x64.
Merge, Split, Compress, and Flatten passed in the owner's Windows 11 VM.
The owner ran `PDF Manager.exe` from the portable ZIP downloaded from
[GitHub RC1](https://github.com/Ali7488/pdf-manager/releases/tag/v0.5.0-rc.1).

## What you can do

- Flatten PDFs for easier viewing, or flatten and merge multiple files.
- Merge PDFs, preserving text, links, and bookmarks.
- Split a PDF into individual pages, ranges, or groups.
- Compress PDFs and turn images into PDFs.

The app processes files locally and writes results to new files. LibreOffice
Impress enables optional PowerPoint conversion. Tesseract enables optional
OCR. Windows acceptance for these optional features and the interactive
desktop installer remains open.

## Portable Windows build

1. Download `PDF-Manager-0.5.0-browser-windows-x64.zip` from
   [GitHub Releases](https://github.com/Ali7488/pdf-manager/releases).
2. Compare its PowerShell `Get-FileHash` result with `SHA256SUMS.txt`.
3. Extract the entire ZIP and open `PDF Manager.exe` from the extracted folder.
   The app opens in your default browser. If it reports a missing Python DLL,
   install the [Microsoft Visual C++ Redistributable for x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)
   at version 14.44 or newer and retry.
4. Use **Settings → About** to check the source revision. Use
   **Settings → Quit PDF Manager** to stop the app.

The desktop setup EXE remains a test artifact while its Windows acceptance
and SDK source review are open. See [the packaging guide](../../packaging/README.md)
and [the release licensing notes](../../LICENSING.md).
